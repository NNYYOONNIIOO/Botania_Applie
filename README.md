# Botania Applie / 植物应用

## 简介 / Introduction

**中文**

Botania Applie 是一个 Minecraft 1.12.2 模组，将植物魔法（Botania）的魔力系统与应用能源2（Applied Energistics 2）深度整合。允许玩家将魔力存储到AE2的存储元件中，并通过ME网络进行魔力传输和管理。

**English**

Botania Applie is a Minecraft 1.12.2 mod that deeply integrates Botania's mana system with Applied Energistics 2 (AE2). It allows players to store mana in AE2 storage cells and manage mana transmission through ME networks.

---

## 主要内容 / Main Features

### 魔力存储元件 / Mana Storage Cells

**中文**

- 支持多种容量的魔力存储元件：1k、4k、16k、64k、256k、1M、4M、16M、64M、256M、1G
- 可直接插入AE2驱动器中使用
- 支持在ME终端中查看存储的魔力

**English**

- Multiple capacity mana storage cells: 1k, 4k, 16k, 64k, 256k, 1M, 4M, 16M, 64M, 256M, 1G
- Compatible with AE2 drives
- View stored mana in ME terminals

---

### 福鲁伊克斯魔力池 / Fluix Mana Pool

**中文**

- 结合了植物魔法魔力池与AE2网络功能
- 占用1个ME频道
- 联网时可从网络中存取魔力
- 支持魔力转换配方
- 离线时自动断开网络连接

**English**

- Combines Botania mana pool with AE2 network functionality
- Occupies 1 ME channel
- Access mana from the network when connected
- Supports mana infusion recipes
- Automatically disconnects when offline

---

### ME终端集成 / ME Terminal Integration

**中文**

- 在ME终端中显示虚拟魔力流体
- 手持魔力容器可快速交互：
  - 左键：执行魔力交换（填充/提取）
  - 右键：将物品存入网络
- 支持泰拉粉碎者等特殊魔力容器

**English**

- Display virtual mana fluid in ME terminals
- Quick interaction with mana containers:
  - Left-click: Execute mana exchange (fill/extract)
  - Right-click: Deposit item into network
- Supports special mana containers like Terra Shatterer
